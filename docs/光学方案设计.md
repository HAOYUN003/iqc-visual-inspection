# 光学成像方案设计（Phase 1 硬件落地）

> 面向半导体设备厂 IQC：标准件 + 机加工件的光学成像检测方案
> 定位：先保证成像质量，再谈 AI。本文档给出从"检测指标"到"相机/镜头/光源/标定"的量化设计路径。

---

## 1. 设计输入：检测指标

| 检测对象 | 关键缺陷/指标 | 量级 |
|---|---|---|
| 标准件（螺钉/垫片/螺母） | 规格防错、螺纹损坏、头部磕碰 | 特征 ≥ 0.1 mm |
| 机加工件（铝/不锈钢） | 划痕、裂纹、麻面、毛刺 | 缺陷宽 0.02~0.5 mm |
| 尺寸要求（精密件） | 直径、位置度公差 | 公差 ±0.01~±0.1 mm |

**核心原则：最小可检缺陷要覆盖 3~5 像素**，否则 AI 模型无法稳定识别。

---

## 2. 光学分辨率与放大倍率计算

### 2.1 物面分辨率的确定

以检测 0.02 mm 宽的划痕为例（加工件表面）：

```
可靠检出所需像素数   ≈ 3~5 px
物面分辨率 required = 缺陷尺寸 / 像素数 = 0.02 / 3 = 6.7 μm/px
                    （更严：0.02 / 5 = 4 μm/px）
```

### 2.2 相机 + 镜头选型

已知相机像素尺寸，反推所需放大倍率：

```
物面分辨率 = 像素尺寸 / 放大倍率 M
⇒ 放大倍率 M = 像素尺寸 / 物面分辨率
```

| 相机 | 分辨率 | 像素尺寸 | 检测 0.02mm 所需 M | 检测 0.1mm 所需 M |
|---|---|---|---|---|
| 500 万像素工业相机 | 2448×2048 | 3.45 μm | ≈ 0.9 | ≈ 0.18 |
| 1200 万像素工业相机 | 4024×3036 | 3.10 μm | ≈ 0.8 | ≈ 0.16 |
| 2000 万像素工业相机 | 5472×3648 | 2.40 μm | ≈ 0.6 | ≈ 0.12 |

**结论**：检测 0.02mm 级划痕需要接近 1:1 的放大倍率（近摄/显微镜头），视场小、工作距离近，产线节拍受限；检测 0.1mm 级缺陷可用 0.15~0.2 倍镜头，视场可覆盖 Φ20~30mm，较为现实。

### 2.3 视场与工作距离

```
视场(FOV) = 相机传感器尺寸 / 放大倍率 M
工作距离(WD) ≈ 焦距 f × (1/M + 1)   （薄透镜近似）
```

例：1/1.8" 传感器（7.2×5.4mm），M=0.2 → FOV = 36×27mm；焦距 25mm → WD ≈ 150mm。

### 2.4 景深估算

```
景深 DOF = (2 × N × COC) / M²     N: F数  COC: 容许弥散圆
```

高倍率下景深急剧变窄（M=1 时 DOF 通常 <1mm），必须**严格控制零件定位与表面平面度**，或采用远心镜头、多站拍摄。

## 3. 光源设计

同一缺陷，打光方式不同对比度天差地别。按缺陷类型选源：

| 缺陷类型 | 推荐光源 | 光学原理 |
|---|---|---|
| 划痕/擦伤 | 低角度环形光（60~75°） | 表面划痕散射增强，亮线显现 |
| 裂纹 | 同轴光 / 背光 | 裂纹打断反射连续性，出现暗线 |
| 凹坑/凸起 | 低角度条形光（成对） | 凸起/凹陷产生明暗阴影 |
| 金属镜面反光 | 偏振光（起偏+检偏） | 消除镜面反射，突出非镜面缺陷 |
| 尺寸测量 | 背光（平行光） | 高对比边缘，支撑亚像素定位 |
| 螺纹/深孔 | 同轴点光 / 内窥 | 解决阴影遮挡 |

**低角度照明**：划痕/毛刺在斜射光下散射显著增强，是机加工件首选的照明策略。

---

## 4. 图像标定：像素 → 物理尺寸

尺寸测量必须经过标定，AI 不做像素级猜测：

```
物理尺寸 = 像素距离 × 标定系数 + 系统偏差
```

- **标定板法**：棋盘格/圆点阵列，确定像素↔mm 映射与畸变系数（张正友标定）
- **双线性畸变校正**：径向 + 切向畸变，消除镜头边缘畸变对测量影响
- **亚像素边缘提取**：Canny + 灰度质心/多项式拟合，定位精度可达 0.1~0.3 像素
- **判定**：测量值 ± 测量不确定度 vs 图纸公差 → OK/NG

**精度预算**（举例）：像素尺寸 3.45μm，放大倍率 0.5，亚像素 0.2px →
测量重复精度 ≈ 3.45 / 0.5 × 0.2 = 1.4 μm，满足 ±0.01mm 公差判断。

## 5. 成像质量验证指标

| 指标 | 说明 | 验收 |
|---|---|---|
| MTF | 调制传递函数，衡量对比度保留能力 | 截止频率处 ≥ 0.2 |
| 畸变 | 桶形/枕形畸变 | ≤ 0.1%（远心镜头更优） |
| 景深 | 清晰成像深度 | 覆盖零件表面起伏 |
| 分辨率 | 实测可分辨的最小线对 | ≥ 最小缺陷要求 |
| 光照均匀性 | 视场内灰度均匀度 | 偏差 ≤ ±10% |

**先保证 MTF/畸变/景深达标，再谈 AI 误判率。**

---

## 6. 推荐硬件配置（预算分级）

### 方案 A：入门验证（~¥5k）
- 相机：海康/大华 500 万像素面阵相机（USB3.0）
- 镜头：16mm 定焦 C 口（M=0.15~0.2）
- 光源：低角度环形光 + 背光板 + 光源控制器
- 适用：标准件规格识别 + 粗级缺陷筛查

### 方案 B：精密检测（~¥20k）
- 相机：1200 万像素工业相机
- 镜头：远心镜头（低畸变、大景深）
- 光源：多角度组合照明 + 偏振
- 适用：加工件划痕/麻面 + 尺寸测量

### 方案 C：超精密（~¥50k+）
- 结构光/激光轮廓仪：3D 表面轮廓检测
- 三坐标（CMM）离线复测：尺寸仲裁
- 适用：±0.01mm 级公差、3D 缺陷

---

## 7. 光学 → AI 融合要点

1. **先标定后训练**：训练数据与部署成像条件一致，避免域偏移
2. **光照不变性**：增广时模拟不同打光（亮度/对比度/低角度效果）
3. **成像质量先行**：成像模糊时模型误判是系统性的，无法靠更多数据解决
4. **光学与 AI 分工**：尺寸 → 光学测量（传统CV）；外观 → AI 分类检测；两者互补

## 8. 从 Phase 0（软件原型）到 Phase 1（硬件落地）的迁移路径

| 阶段 | 采集 | 检测 | 数据 |
|---|---|---|---|
| Phase 0（当前） | 手机/电脑镜头 | CNN规格 + YOLO缺陷 | 模拟 + 公开数据 |
| Phase 1（硬件） | 工业相机+光源 | 同架构重训练 + 尺寸标定 | 企业真实零件 |
| Phase 2（落地） | 产线集成 | 节拍优化 + 自动化 | 质量数据资产闭环 |

核心：**Phase 0 的代码架构与 Phase 1 完全复用**，只需替换数据来源与相机驱动层，即可平滑升级。
